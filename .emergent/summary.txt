Build a web admin panel for a Ministry with a Microsoft/Fluent-inspired UI. The application should support three user roles (Admin, Editor, Approver) with specific permissions.

PRODUCT REQUIREMENTS:
- **UI:** Left sidebar, top command bar, table-first pages, light neutral theme, subtle borders, 8px radius, and Segoe UI/system-ui typography.
- **Data Models:** User, Task, Comment, and AuditLog.
- **Task Status Flow:** A strict lifecycle for tasks: Draft -> Submitted -> Producing -> Review -> (Scheduled or Rejected) -> Published.
- **Role Permissions:**
    - **Editor:** Create/edit non-finalized tasks, submit for review.
    - **Approver:** Approve/reject tasks in the 'Review' state.
    - **Admin:** Full access to all data and status transitions.
- **Business Rules:**
    - Task fields become read-only for Editor/Approver once 'Scheduled'.
    - A placeholder for video upload is required, with a rule that tasks cannot be 'Published' without a video (to be implemented in Phase 2).
    - Inline validation errors are required.
- **Pages:** Dashboard, Tasks (with search, filter, sort), Task Details (with tabs: Details, Comments, Activity, Video), Calendar (month/week view), Activity Log, and Settings (Admin-only).
